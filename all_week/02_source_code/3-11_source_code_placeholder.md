# 3-11 Source Code

The application source is split by responsibility:

- `frontend/` contains the calendar interface (`index.html`, `styles.css`, `app.js`).
- `backend/` contains the Node.js REST API, package manifest, and Dockerfile.
- `../03_database/` contains PostgreSQL schema and seed scripts.
- `../04_docker/` contains Docker Compose configuration.

Run the complete application with Docker Compose from the repository root. See `../04_docker/3-11_05_Docker_Instructions.md`.
